# 캐릭터 시트 (character_sheet_916.png)

상황극 그림에 같은 인물이 계속 나오게 하려면 이 폴더에 **세로 9:16 비율**의
참조 사진(캐릭터 시트) 한 장이 필요합니다. 파일 이름은
`character_sheet_916.png` 로 저장하세요 (config.yaml 의 `character.sheet_path` 기본값).

## 만드는 방법

1. 정면 얼굴이 잘 나온 사진을 1~2장 준비합니다 (본인 사진 또는 AI로 만든 얼굴 사진).
2. 세로 9:16 캔버스 하나에 이렇게 배치합니다:
   - 위 40%: 얼굴 클로즈업 2컷
   - 아래 60%: 전신 사진 1컷
3. **여백을 회색이나 흰색으로 채우지 마세요.** 그 여백 색까지 그림에 그려집니다.
   사진들로 캔버스를 완전히 꽉 채우세요.
4. 완성한 파일을 `character_sheet_916.png` 로 저장합니다.
5. config.yaml 에서 `character.use_face: true` 로 바꿉니다.

## 얼굴을 안 쓰고 싶다면

이 폴더를 비워두고 `character.use_face: false` (기본값)로 두면 됩니다.
그러면 씬 분할이 사람 대신 사물·손·화면·풍경 위주로 장면을 잡습니다.

# 쇼츠 씬 분할 프롬프트

너는 세로 쇼츠 영상의 씬(장면)을 나누는 편집 보조자다. 아래 대본을 문장 번호 그대로
유지한 채, 화면에 무엇을 보여줄지 씬 단위로 나눠라.

## 채널 정보
- 채널/주제: {{CHANNEL_TOPIC}}
- 시청자: {{AUDIENCE}}
- 인물 참조 시트 사용 가능 여부: {{HAS_CHARACTER_SHEET}}

## 문장 목록 (번호는 0부터 시작, 절대 합치거나 순서를 바꾸지 마라)
{{SENTENCES}}

## 규칙
1. 모든 문장 번호가 정확히 하나의 씬에 포함되어야 한다. 빠뜨리거나 중복 배정하지 마라.
2. 씬 개수는 보통 문장 2~3개당 1개 정도가 적당하다 (너무 잘게 쪼개지 마라).
3. `image_prompt` 는 그 씬에서 보여줄 장면을 한국어로 묘사한다. 아래를 반드시 지켜라:
   - "화면을 가득 채우는 한 장의 사진" 이라고 명시할 것
   - 여백, 위아래 빈 공간, 분할 화면, 콜라주라는 표현은 절대 쓰지 말 것
   - 이미지 안에 문자·숫자·로고·의성어·말풍선이 들어가면 안 된다고 명시할 것
   - 사람이 나오면 반드시 "진행자"라고만 지칭하고, 나이·외모(예: 20대 여성)는 절대 쓰지 말 것
     ({{HAS_CHARACTER_SHEET}} 가 "없음"이면 사람 대신 사물·손·화면·풍경 위주로 묘사할 것)
4. `person` 은 그 씬에 사람(진행자)이 나와야 하면 true, 사물/풍경 위주면 false.
5. 시간(초)은 적지 마라. 실제 타이밍은 프로그램이 음성 분석으로 다시 계산한다.
6. 대본에 없는 내용(강조어, 효과음 등)을 지어내지 마라.

## 출력 형식
다른 설명 없이, 아래 형식의 JSON 하나만 출력하라.

```json
{
  "scenes": [
    {
      "id": 1,
      "sentence_indices": [0, 1],
      "image_prompt": "화면을 가득 채우는 한 장의 사진으로, ...",
      "person": true,
      "note": "짧은 한국어 설명"
    }
  ]
}
```
